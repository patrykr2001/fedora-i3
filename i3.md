# Additions for i3

## Picom compositor

Install:
```bash
sudo dnf install picom
```

Basic config:
```bash
mdkir -p ~./config/picom
nano ~/.config/picom/picom.conf
```

Write:
```
# Backend
backend = "glx";
glx-copy-from-front = false;
vsync = true;

# Shaows
shadow = true;
shadow-radius = 12;
shadow-offset-x = -8;
shadow-offset-y = -8;
shadow-opacity = 0.6;
shadow-exclude = [
  "name = 'Notification'",
  "class_g = 'i3bar'",
  "class_g = 'i3-frame'",
  "_GTK_FRAME_EXTENTS@:c"
];

# Fading
fading = true;
fade-in-step = 0.03;
fade-out-step = 0.03;
fade-delta = 5;

# Transparency
active-opacity = 0.95;
inactive-opacity = 0.9;
frame-opacity = 1.0;
inactive-opacity-override = false;

# Corners
rounded-corners-exclude = [
  "class_g = 'i3bar'",
  "class_g = 'i3-frame'"
];

# Blur background
blur-method = "dual_kawase";
blur-strength = 6;
blur-background = true;
blur-background-frame = false;
blur-kern = "3x3box";
blur-exclude = [
  "class_g = 'i3bar'",
  "name = 'Notification'"
];

# Performance
mark-wmwin-focused = true;
mark-ovredir-focused = true;
detect-rounded-corners = true;
detect-client-opacity = true;
detect-transient = true;
detect-client-leader = true;
use-damage = true;
log-level = "warn";```

Add to `~/.config/i3/config`:
```bash
exec_always --no-startup-id picom --config ~/.config/picom/picom.conf
```

Reload i3:
```bash
i3-msg restart
```

## Feh wallpaper

Install:
```bash
sudo dnf install feh
```

Set wallpaper:
```bash
feg --bg-scale ~/Pictures/wallpaper.jpg
```

Add to `~/.config/i3/config` for it to load automatically:
```bash
exec_always --no-startup-id feh --bg-scale ~/Pictures/wallpaper.jpg
```

Display modes:
 - `--bg-scale` - stretches to screen size
 - `--bg-fill` - fill keeping the proportions
 - `--bg-center` - center without scaling
 - `--bg-tile` - tiling

## i3 borders

Edit `~/.config/i3/config` and add:
```
default_border normal 0
default_floating_border normal 2
```

This will remove borders from tilling windows, but keep the top bar. It doesn't change floating windows.
