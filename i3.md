# Additions for i3

## Picom compositor

Install:
```bash
sudo dnf install picom
```

Basic config:
```bash
mdkir -p ~./config/picom
nano ~/.config/picom/picom.conf
```

Write:
```
backend = "glx";
vsync = true;
fading = true;
fade-in-step = 0.05;
fade-out-step = 0.05;

# Przezroczystość
inactive-opacity = 0.9;
active-opacity = 1.0;
frame-opacity = 1.0;

# Blur (wymaga picom fork - pika-compositor lub picom-git)
# blur-method = "dual_kawase";
# blur-strength = 5;

# Zaokrąglone rogi
corner-radius = 8;
```

Add to `~/.config/i3/config`:
```bash
exec_always --no-startup-id picom --config ~/.config/picom/picom.conf
```

Reload i3:
```bash
i3-msg restart
```
